# 🚨 튜터 출동! 스마트교실 구조대

> 2026 부산 디지털튜터 양성센터 지역특화과정 **1·2·3차시 체험 미션 웹게임**
> 부산 명진초등학교 최일훈 (2026)

로그인에 막힌 민준, 친구 사진을 올리려는 유나, 무한 로딩에 갇힌 하린… 교실 곳곳의 SOS를 해결하며 디지털튜터의 역할·보안·에듀원 2.0을 몸으로 익히는 웹게임입니다. 설치·로그인·서버 없이 브라우저에서 바로 실행됩니다(PC·태블릿·휴대폰).

## 구성
| 구역 | 차시 | 미션 |
|---|---|---|
| 튜터 본부 | 1차시 · 부산 디지털 교육의 미래와 튜터의 사명 | 한 단어 체크인 · 교실 스캔 · 격차 분류소 · 페르소나 출동(민준·서아·지후·김 담임) · 5초 판단 · 사명 선언 카드 · 확인 퀴즈 |
| 보안 관제탑 | 2차시 · 부산 지역 디지털 교육 환경 탐색·직무 정립 | 멈춤의 순간 체크인 · 개인정보 숨은그림찾기 · 보안 수칙 OX · 장애 접수 티켓 · 페르소나(도윤·유나·박 정보부장) · 지원 계획 빌더 · 확인 퀴즈 |
| 에듀원 클라우드 섬 | 3차시 · 부산 에듀원 2.0 시스템 이해 | 접속 체크 · 4대 기능 카드 뒤집기 · 구조 쌓기 · 타임싱크 실험실 · 위기 대응 시뮬레이터(하린·태오) · 나의 첫 클래스 인증 · 확인 퀴즈 |
| 공유 광장 | — | 산출물 모아 보기, 공유 글 복사 → 패들렛 |
| 수료 무대 | — | 도장 21개 · 수료증 그림 저장 |

- 구역에 처음 들어가면 **SOS 브리핑**으로 그 차시의 학생·선생님이 등장해요.
- 롤플레이는 세 갈래 선택지 대화. 좋은 대응이면 게이지가 오르고 표정이 밝아져요.
- 🔑 강사 메뉴(지도 화면 아래): 참여 QR(+패들렛 주소), 시연용 도장 채우기, 기록 지우기 — 강사 코드는 `config.js`의 `teacherCode`(기본 `2026`).

## 폴더
```
index.html          게임 (타이틀·지도·구역·공유 광장·수료 무대)
config.js           강사 설정 (패들렛 주소, 에듀원 주소, 강사 코드)
css/ js/            화면·미션 코드 (js/data.js에 교안 내용 데이터)
assets/             그림 (키아트·지도·구역 배경·캐릭터·인물·아이콘)
guide/              운영·제작 가이드 (그림 프롬프트, 크로마키 코드, 배포 방법)
```

기록은 각 브라우저(localStorage)에만 저장되며 서버로 보내지 않습니다.
